# Хмеля Шава — сайт мережі шаурми

Сайт-вітрина українською мовою: головна, меню з цінами та сторінка точок у 9 містах
(Луцьк, Львів, Київ, Одеса, Харків, Дніпро, Вінниця, Івано-Франківськ, Хмельницький).
Онлайн-замовлення й оплати немає.

## Запуск

Потрібен Node.js 20 або новіший.

```bash
npm install
```

```bash
npm run dev
```

Сайт відкриється на http://localhost:3000.

## Що потрібно заповнити справжніми даними

Зараз на сайті стоять приклади та заглушки. Усе змінюється в трьох файлах, код чіпати не треба.

| Файл | Що в ньому |
| --- | --- |
| `src/data/menu.ts` | Страви, опис, вага та ціни — **приклад**, замініть на справжнє меню |
| `src/data/locations.ts` | Міста й точки. Адреси — **приклади для макета**: вулиці справжні, але закладу за ними немає; замініть перед публікацією. Графік і телефон точки можна вказати окремо, якщо вони відрізняються від спільних |
| `src/data/site.ts` | Назва, слоган, спільний графік (щодня 09:00–23:00) і телефон. Пошта та Instagram — **заглушки** |

Тексти переваг на головній («Готуємо при вас» тощо) лежать у `src/app/page.tsx` — перевірте,
що вони відповідають тому, як працює заклад.

Коли в точки з'являється адреса, на її картці автоматично показується кнопка «Прокласти маршрут».
У місті може бути кілька точок: додайте ще один об'єкт у `points`.

## Структура

```
src/app/page.tsx            головна
src/app/menu/page.tsx       меню
src/app/locations/page.tsx  точки за містами
src/components/             шапка, підвал, картка страви, ілюстрація
src/data/                   меню, міста, контакти
```

Технології: Next.js 16, TypeScript, Tailwind CSS 4. Бази даних немає — усі сторінки статичні.

## Фотографії

Фото в `public/photos` — зі стоку Unsplash (ліцензія Unsplash дозволяє комерційне використання).
Це ілюстрації, а не знімки страв закладу. Коли з'являться власні фото, покладіть їх у ту саму
папку під тими самими назвами (`hero.jpg`, `grill.jpg`, `shawarma.jpg`, `hotdogs.jpg`, `burgers.jpg`,
`combo.jpg`, `snacks.jpg`, `sauces.jpg`, `drinks.jpg`) — сайт підхопить їх без змін у коді.

Три категорії з позначкою `featured` у `src/data/menu.ts` (шаурма, хот-доги, бургери) показуються
великими картками на головній; картка відкриває меню одразу на своїй категорії (`/menu?c=burgers`).
